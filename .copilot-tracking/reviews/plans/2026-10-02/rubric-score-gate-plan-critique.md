## Highest-Impact Finding

PC-001: the gate executes PR-controlled scripts and config with write permissions, so a PR can approve itself. The smallest fix is to run scripts and rubric config from `origin/main` and treat the PR head only as scored data.

## Limitations

* gh-aw support for an `if: always()` finaliser that depends on the agent and custom safe-output jobs is not established by the supplied evidence. PC-003 asks the implementer to verify it and provides a documented fallback.
* GitHub server-side handling of `merge=union` was not verified (PC-018).
* No live run was possible. All findings are design-level.
