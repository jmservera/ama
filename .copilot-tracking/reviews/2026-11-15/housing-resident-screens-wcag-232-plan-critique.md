### PC-004 - Unimplemented scrollIntoView and missing programmatic heading focus CSS contradict FR-03 and P03-T01

* Severity: High
* Related IDs: FR-03, C4, C7, P01-T02, P03-T01
* Evidence:
  * `src/api/src/zava_forward/api/web/role-screens.js:270-276` currently implements `const link = event.target.closest?.("a[data-jump]"); if (!link) return; event.preventDefault(); document.getElementById(link.getAttribute("data-jump"))?.focus();`. Contrary to `research.md:76-82`, it does not invoke `.scrollIntoView?.({ block: "nearest" })` and does not guard `event.target?.closest`. Yet `FR-03` (`.copilot-tracking/plans/2026-11-15/housing-resident-screens-wcag-232-plan.md:53`) requires scrolling target headings into view and `P03-T01` (`phase-details.md:275-278`) specifies `test_jump_link_click_focuses_target_heading_without_hash_route_change` asserting `.scrollIntoView({ block: "nearest" })` is called, while `P01-T02` schedules no update to the listener.
  * `plan.md:40` and `research.md:83, 108` state that `src/api/src/zava_forward/api/web/style.css:355` already contains `.screen-record h2:focus` rules. In reality, `style.css` ends at line 303, defines `:focus-visible` at `style.css:42` and `.screen-links` at `style.css:297`, and has no `:focus` rule for programmatic focus targets (`[tabindex="-1"]:focus` or `h2[tabindex="-1"]:focus`). When a jump link is activated by pointer click and JavaScript calls `.focus()` on a non-interactive `<h2 tabindex="-1">`, browsers commonly do not match `:focus-visible`, leaving the focused heading without a visible focus indicator (WCAG 2.2 SC 2.4.7).
* Impact: `P03-T01` fails on the missing `scrollIntoView` call, and pointer-triggered jump-link focus on `<h2 tabindex="-1">` lacks a guaranteed visible Fluent 2 focus ring.
* Smallest useful change: Update `P01-T02` to store `const target = document.getElementById(link.getAttribute("data-jump")); target?.focus(); target?.scrollIntoView?.({ block: "nearest" });` (with `event.target?.closest?.("a[data-jump]")`) in `role-screens.js:270-276`, bring `src/api/src/zava_forward/api/web/style.css` into scope in `plan.md` and `P01-T02` to extend `style.css:42` with `[tabindex="-1"]:focus` using only existing Fluent focus tokens (`--strokeFocusWidthThick`, `--colorStrokeFocus2`, `--colorStrokeFocus1`, zero raw hex colours per `src/api/tests/test_design_system.py`), and align `P03-T01` CSS assertions with the actual rule.
* Action owner: planner
* Resolving evidence: Updated `Files in Scope`, `P01-T02`, and `P03-T01` in `.copilot-tracking/plans/2026-11-15/housing-resident-screens-wcag-232-plan.md` and `.copilot-tracking/details/2026-11-15/housing-resident-screens-wcag-232-phase-details.md` covering `scrollIntoView?.({ block: "nearest" })` in `role-screens.js` and `[tabindex="-1"]:focus` token styling in `style.css`.
