# Details: Phase 0 baseline and wait analysis (Refs #124)

* `baseline_summary`: window counts, before and after, exclusions by reason, open unknown outcomes, duplicate ids.
* `leg_days`: three handover legs; None when missing or out of order.
* `waits_by_party`: calendar days per named party, unattributed visible, unknown or disputed cause counts.
* `loop_counts`: return, rejection, repeat visit, reopen per property.
* Not in slice: active time, primary delay code rules, extract import, persistence, UI.
