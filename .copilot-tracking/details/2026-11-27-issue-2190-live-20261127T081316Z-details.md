## Phase 1

`server_activate` runs after bind/listen: call `self.socket.setblocking(False)`. Override `get_request` to set the accepted socket blocking, because BSD derived systems inherit the flag. `BlockingIOError` is an `OSError`, so `_handle_request_noblock` returns and `serve_forever` re-checks the shutdown flag.

## Phase 2

Test: on an idle `_Server`, `_handle_request_noblock()` returns within 5 s in a helper thread (it blocks forever without the fix); the accepted socket of a real connection is blocking.
