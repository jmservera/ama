# Details: keyboard probe correction C1 (2026-11-10)

* Walk-level negative design: the negative runs the same `walk_screen` function against a page that has a mutation installed through an `init_script`-free hook: `walk_screen(..., mutate=...)` applies the mutation after the target is reached and before the assertion, and the negative control catches the `AssertionError` raised by the SAME `check`-style assertion (a local `require` that raises). Production walks use `check`; negatives assert the raised message names the targeted assertion.
* Focus: `focus_visible` is evaluated right after each Tab or Enter that reaches a target, and asserted. Mutation: add a `<style>` rule `a[data-reset]:focus-visible{outline:none!important;box-shadow:none!important}` before reaching reset.
* Status: `status_contract(page)` reads `role`, `aria-live`, `aria-atomic` and text; `wait_status` waits for text then asserts attributes. Mutation: remove the three attributes while text stays correct.
* Regions: `region_inventory(page)` returns each `.screen-evidence table` ancestor `.table-scroll` / `[role=region]` info (has_region, label, tabindex) plus total tables, independent of label and tabindex. Expectations: `REQUIRED_REGIONS` (screen id to minimum count) from the prior observation: resident-choice, hazard-triage, asset-board, programme-queue, technical-queue, safety-lead, data-operator, contractor-job-pack each >= 1; `NO_REGION_GAPS` for resident-service-issues, quality-queue, procurement-packages, finance-invoices, finance-funding (reported as explicit gaps; if a table exists on them it must still be labelled and focusable). Every counted region is reached by Tab. Mutations: delete the label; remove the regions.
* Known limit: expected minimums derive from one prior observation on constructed fixtures for the first listed home; a data-dependent change will fail loudly rather than silently reduce coverage.

## Critique amendments (applied)

* Region expectations are exact counts, not minimums, with a single-region-removal negative.
* Focus visible requires outline-style not none, width of at least 2px and non-transparent colour, or a non-none box-shadow; add an invisible-indicator (transparent outline, no shadow) negative.
* Status negatives remove role, aria-live, aria-atomic independently with text retained; each must fail the walk assertion.
