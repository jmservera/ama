## Research Cycle Log

Cycle 1 Wider: inspected the existing progress API, chart/table renderer,
archive filters, prior Review and component guides. Scope already exists;
the latest prior Review reports residual live/publication work, not an
implementation defect. Reflection: a rebuild would add risk without delivering
the missing evidence.

Cycle 1 Deeper: traced synthetic admission, lifecycle replay, UTC ranges,
nearest-rank p90, recorded overdue tasks, AI briefing reviews and filtering
before stable ID paging. Existing unit cases cover JSON/SQLite; the browser
fixture has only 26 cases. The existing seed-174 scale generator supplies
60,000 wholly fictional homes, without reading private geography. Reflection:
use this existing fixture with explicitly constructed lifecycle overlays to
exercise the real progress/archive at stock scale, retaining small semantic
tests. A locked focused baseline was launched; current execution is pending.

Cycle 1 Contrarian: challenged stock-versus-case denominators, random event
semantics and inferred AI use. The scale fixture's generic event kinds do not
prove openings/closings; a labelled test overlay must provide known transitions,
not reinterpret those events or pretend to recreate private 980-case lineage.
The issue's owner comment keeps live-site acceptance outstanding. Native
Fluent-derived tokens do not establish full Fluent implementation adoption.
Official Fluent page attempts return a not-found page; retrieval is partial,
not fresh complete Fluent review. Reflection: retain these limitations, use
the existing local design-system specification and avoid runtime changes.

Parent synthesis: accepted C1-C6, W1-W2. Select scale regression and actual
local browser evidence over feature rebuild or live sign-in. No source
defect justifies runtime edits. Re-entry is unnecessary: in-scope contracts
are established; execution and independent review belong to later phases.
