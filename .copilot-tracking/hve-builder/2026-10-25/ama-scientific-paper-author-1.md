## Architecture and Local Hypothesis

One user-selectable agent can support writing, revision and assisted review
through explicit modes, common evidence states and genre-sensitive decisions,
without a wider orchestrator. This is the caller's falsifiable local hypothesis,
not a behavior result.

The selectable agent owns the operating protocol. The compact method reference
owns optional techniques, genre qualifications and source provenance; it is not
a second agent or a copied guide. The agent explicitly reads that reference at
the start of scholarly work. Index entries aid discovery, not automatic runtime
loading. Capstone routing is conditional and does not impose a subject domain.

The new agent deliberately omits model so direct invocation uses the current
session or model-picker selection. No hooks, handoffs, agent dependencies,
additional agent or skill were added. Tool configuration remained user-managed
and opaque: no selection, recommendation, inspection or comparison was made.
No exact configuration was supplied, so the field was omitted; omission is not
a security guarantee. Host approvals, permissions and restricted sessions are
identified as controls; advisory prose is not represented as enforcement.
