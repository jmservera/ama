## Main-Story Argument

Control one home before adding platforms. Once the evidence and ownership
work, improve repeated preparation, make service easier to reach, and reuse
portfolio history. Each addition must solve a named problem better than its
simpler comparator. The roadmap is a set of conditional recommendations, not
a purchase order, approved delivery dates or measured benefits.

The five replacement/bridge slots retain the existing 50/70/60/60/30-second
allocations. The 54-page structure, 23:45 narration plan, discussion reserve
within 30 minutes and separate ten-minute demo remain. These are planned,
unrehearsed timings. Appendix answers retain deeper comparison detail.

## Required Readiness, Not Optional Innovation

Current access/role denial, relevant SQL/model/transport acceptance, recovery,
meaningful human review, privacy, accessibility and complete cost authority
are applicable release gates. Do not frame them as future features that can
be skipped in favour of another platform. Source components, historical
calls and a cloud resource do not by themselves establish current acceptance.

The [monitoring evidence/gap matrix](../../../infra/monitoring-runbooks.md)
keeps new alert candidates disabled pending actual owners and evidence.
The [29 October hub reconciliation](../../../infra/README.md#bounded-existing-hub-exercise-2026-10-29-refs-140-184-137)
is a bounded real observation; registry permissions and the unapproved custom
receiver still block live-to-SQL acceptance. It is not proof of the complete
source-only private Event Hub route. A narrow later exercise approval is
not Fabric funding or complete all-in headroom.

## Fabric Recommendation And Stop Condition

Retain API/core/Azure SQL as operational authority. Compare one named portfolio
question using the same permitted synthetic projection, cohort, history and
KPI definitions. Measure reconciliation, manual preparation/review effort,
freshness/query behaviour, source load and full cost, plus denial/recovery.
Existing approved spare capacity may improve the case, but is not assumed.

Adopt the least complex configuration that wins the comparison without
weakening controls. If SQL/history plus Power BI meets the need more simply,
keep it. Add analytical Q&A or time-series workloads only for distinct needs.
Mirroring does not inherit application permissions or create retained audit
history. Fabric SQL ledger limits rule out an equivalent operational swap
on the assessed evidence, not all selective current-table replication.

## Audience And Decision

Lead with the next decision for executive/Sergeant preferences, connect to
resident and colleague experience for Therapist preferences, then show the
comparison for Scientist preferences. Make the future tangible for Evangelist
preferences without implying delivered improvement.

Ask for one bounded validation journey, accountable owners and one recurring
portfolio question. Return with an authorized, costed comparison proposal
before paid execution or expansion. Formal approval, spending, resident choice,
legal review, professional judgement and safety routes remain independent.
