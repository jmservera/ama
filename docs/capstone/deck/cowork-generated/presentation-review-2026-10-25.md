## Reproduction and Local Evidence

The [story builder](../../../../tools/cowork-native-recovery/Invoke-StoryReview.ps1)
and [manifest](../../../../tools/cowork-native-recovery/content/story-review.json)
require the exact pre-review source hash. The updated delivered deck is
intentionally not accepted as its own rebuild input. Recover the committed
source into external scratch, then build and verify:

```bash
OUTPUT="$HOME/.local/share/ama/presentation-review-reproduction"
mkdir -p "$OUTPUT"
git show c1e2272a:docs/capstone/deck/zava-forward-cowork-v2-draft.pptx > "$OUTPUT/source.pptx"
pwsh -NoProfile -File tools/cowork-native-recovery/Invoke-StoryReview.ps1 -Action Build -RepoRoot "$PWD" -SourcePath "$OUTPUT/source.pptx" -OutputDir "$OUTPUT"
pwsh -NoProfile -File tools/cowork-native-recovery/Invoke-StoryReview.ps1 -Action Verify -RepoRoot "$PWD" -SourcePath "$OUTPUT/source.pptx" -OutputDir "$OUTPUT"
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python docs/capstone/pitch/cowork-main-presentation/build_assets.py --check-only --check-pptx "$OUTPUT/zava-forward-story-review.pptx"
```

Native Render requires Windows PowerPoint. From WSL:

```bash
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$(wslpath -w "$PWD/tools/cowork-native-recovery/Invoke-StoryReview.ps1")" -Action Render -RepoRoot "$(wslpath -w "$PWD")" -SourcePath "$(wslpath -w "$OUTPUT/source.pptx")" -OutputDir "$(wslpath -w "$OUTPUT")"
```

Full local reports and previews for this run remain outside the checkout at
`~/.local/share/ama/presentation-review-2026-10-25/`. They include
