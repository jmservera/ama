\section{Supplement}\label{sec:supplement}

The Supplement records source qualifications, measurement definitions,
detailed results and execution history. It also retains proposed checks of
the case explanations, an assumed cost model and follow-up design candidates.
Those proposals are not results; their execution and approval status is
specified below. For example, the cost model assumes a growing implementation
premium, while the experiment measured only ten-feature spending.
Section~\ref{sec:experiment} explains the registered base and the disclosed,
unregistered amendments. Historical freezes below are version-specific.

For the result tables, $P_{10}$ means the final ten-feature checkpoint and
CR1 the withheld regional-access extension\@. \armlegend\ Full source and
digest identifiers appear in the end register
(Table~\ref{tab:source-register}); historical records retain their own scope.
