## Source and Terms

All files in `azure/` are byte-for-byte selections from
[Microsoft's Azure architecture icon pack](https://learn.microsoft.com/en-us/azure/architecture/icons/),
[Azure_Public_Service_Icons_V24.zip](https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip),
retrieved 14 October 2026.

Microsoft permits use, copying, distribution and display in architecture
diagrams, training materials and documentation. All other rights are reserved.
Do not crop, flip, rotate, distort, recolour or use these icons to represent
custom products. The drawings preserve the SVG bytes and aspect ratios.
