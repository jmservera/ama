## Defect and fix

`MssqlDb` (law store) opened its own connection with `startup_retries = 0`, so the #2273 retry never covered the law store or rule-card start-up transactions. `MssqlDb` now enables the same bounded retry (8 attempts, backoff 1 to 30 s) and `LawStore.__init__` ends it in a `finally` after rule-card seeding, so runtime requests still fail fast. Files: `src/core/src/zava_forward/core/lawstore.py`, tests in `src/core/tests/test_mssql_startup_lock.py`. Not deployed (owner rule: no production changes).
