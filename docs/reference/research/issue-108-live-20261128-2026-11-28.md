## Gap and change

The 2026-11-24 [record](./issue-108-live-20261124-2026-11-24/serving_region_record.json) was written by hand, and `quota_headroom.status: confirmed` was a self-declared flag the harness trusted. `build_serving_region_record` in `src/agents/src/zava_forward/agents/ai_eval.py` now derives the record from `az cognitiveservices` deployment, usage and model-catalogue JSON. Each deployment resolves through the catalogue `usageName` to a usage row. Headroom is `confirmed` only when every row resolves, current is not above the limit, current covers deployed capacity, and no model is past inference deprecation on the retrieval date; otherwise `unavailable` with reasons. CLI: `python -m zava_forward.agents.ai_eval --build-region REGION DATE ACCOUNT DEPLOYMENTS USAGE MODELS SOURCE`.
