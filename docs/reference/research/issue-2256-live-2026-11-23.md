## Root cause

`handoff_ageing` in `src/core/src/zava_forward/core/workflows.py` raised on a seeded `offered_at` without a timezone (`2026-10-13T09:00`), so `unaccepted_handoffs` dropped the case and the screen said nothing was waiting. Main fixed this in #2258 (`a6c0910c97`): the row stays listed with `age_hours` null, and `waitingRows` in `web/app.js` accepts a null age and the screen prints "Unknown".
