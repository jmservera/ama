## Why no exemption was applied

Excluding `/api` from Easy Auth would let unauthenticated traffic reach the app without platform proof, and the page scripts need the platform principal on their API calls. The issue requires trusted platform-principal proof first. Instead, `test_easy_auth_never_exempts_api_paths` in `infra/tests/test_bicep_policy.py` fails if `modules/containerapps.bicep` or `modules/edge-existing-auth.bicep` list any `/api` path in `excludedPaths`. A mutation that added `/api/me` made it fail; the unmodified modules pass.
