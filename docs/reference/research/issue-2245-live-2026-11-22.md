## Code changes

* `agents/chat.py`: `ChatModel` reports `ai-suspended` when admission returns that code; other denials keep `activation-not-approved`.
* `api/server.py`: `chat_admission` returns `ai-suspended` for an open suspension; `/api/chat/status` adds a plain sentence that answers are on hold and use rules only.
* `core/chat_panel.py`: the fallback and the rules note state the hold instead of missing approval.
* `resident_demo/assistant.py` and `aoai.py`: `expires_at()` reads `ZF_DEMO_EXPIRES_AT` (explicit UTC) and fails closed to the 2026-11-01 default when unset, invalid, naive or non-UTC.
* Tests: `test_open_suspension_is_reported_as_a_hold_not_as_missing_approval` and `test_expiry_follows_zf_demo_expires_at_and_fails_closed`.

The suspension control is not weakened and SUS-1 was not touched.
