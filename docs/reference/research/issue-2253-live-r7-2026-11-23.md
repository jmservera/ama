Refs #2253. Earlier rounds proved label size and circle markers live (revision 0000028) and added a geometry test for in-range data. This round covers a gap: stored or forecast values outside the fixed axis (temperature -10 to 45 C, humidity 0 to 100 %) were plotted outside the 10..150 plot area, over the tick labels or off the viewBox.

Fix: `yFor` in `sensorChart` clamps the mark position; exact values remain in the description and table. Proof: a node-run test in `src/api/tests/test_epic149_child_ux_contracts.py` feeds 60 C, -30 C and a 99 C forecast and asserts every mark lies within 10..150; it fails without the clamp.

| No overlap | Proven locally; live needs the current main image deployed |
| Circle markers | Proven live (r5) |
| Not one thick stroke | Proven locally; live needs deployment |
| Forecast squares | Proven locally |
| Narrow screens | Not applicable, desktop-only demo |

Deployment of the new image is an owner action; no Azure change was made.
