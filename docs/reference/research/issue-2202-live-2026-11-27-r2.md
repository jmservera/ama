## Probe defect found and fixed (not product)

The first chat run showed routing lines shifted by one question (funding showed the Quality line) and one Send click timed out. Cause: the probe read the routing count before the previous answer finished, and the widget keeps Send disabled during an ask (about 25 to 50 s per ask with the model). The corrected probe waits for Send to be enabled, then counts. The product behaviour is correct; the earlier offset came from the probe. Asks take 25 to 50 s here, which is model latency, not a #2202 criterion.
