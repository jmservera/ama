## Why no source change

The clock fails closed in `hazard_clock` (`src/core/src/zava_forward/core/taskqueues.py`) when `aware_at` or `response_due_at` is missing. The fix is data, applied earlier by `infra/scripts/seed_demo_hazard_clock.py`. `SqlStore.merge_seed` is insert-only and the demo dataset generator is outside this repository, so surviving a re-seed needs a data-changing re-seed or a generator change; neither is in scope for a read-only pass.
