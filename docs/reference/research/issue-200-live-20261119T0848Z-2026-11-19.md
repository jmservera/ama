## Why no fresh push

The registry `crcutovertestrzsrg` still reports `publicNetworkAccess` Disabled and default action Deny (`live-probe-20261119.txt`). A push needs the short public window described in `infra/README.md`. That window changes a shared registry posture and a new revision would replace the revision other live checks use; the 2026-11-18 owner decision authorises neither as a routine step ("no production changes"). The criterion needs no code or test change: the Dockerfile, check script and Bicep commands are already ticked and covered.
