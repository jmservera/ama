## Change

When the map sensor overlay fails, the warning in `assistants.py` already carried `cause=sql-write-lock-busy` for a lock timeout. For any other failure it said only `cause=other`. It now appends `sqlstate=<code>`, taken by `driver_sqlstate` in `mssqlstore.py` from the driver exception chain. Only a five-character code is logged, never the driver message. Test: `test_an_other_overlay_failure_logs_only_the_sqlstate_code` in `src/api/tests/test_map_sensors.py`.
