Issue #1844 reports that at 320 and 390 px the open home summary covers map markers and zoom controls. This note re-proves each unticked criterion on `main` at `342fad401d` and against the live demo revisions API `ca-cutover-test-demo-api--0000054` (created 2026-11-22T23:14Z, healthy, 100 percent traffic) and resident `ca-resident-demo--0000026`. No source file changed on this branch. Earlier audits: [2026-11-22](./issue-1844-live-20261122-2026-11-22.md) and [2026-11-19](./issue-1844-live-20261119-2026-11-19.md). Scope is the synthetic desktop demo (owner decisions 2026-11-18).

## Finding

The fix is on `main` (commit `21b810439f`, #2155): `style.css:514` sets `.map-home-card{position:static;...}` at `max-width:600px`, and `check_narrow_summary_clearance` in `src/api/checks/map_fullscreen_browser_check.py` is the regression. `style.css` and that check are unchanged since the 2026-11-22 audit. The employee map lives only in the API app; the resident app (`ca-resident-demo`, revision 0000026) serves no map, so it is not a surface for this issue.
