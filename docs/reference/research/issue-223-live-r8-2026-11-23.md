Refs #223. Synthetic desktop demo; owner decisions of 2026-11-18 apply. No Azure resource was created or changed.

## Change

[run 7](issue-223-live-r7-2026-11-23.md) found that effort in the review-effectiveness report is scripted units, not time. `ai_tasks.review()` now stores `review_seconds` (record creation to review, clamped at 0, `null` if a timestamp does not parse) inside `review_evidence`, so each live review carries a measured effort alongside reviewer, source hashes and reason.

## Evidence

* `src/api` `tests.test_ai_tasks` and `tests.test_epic104_human_override_audit`: 94 tests OK, including `test_review_evidence_retains_elapsed_review_seconds` (150.0 s for a 2 minute 30 second gap, clamp, unparseable input).
* `src/core` `tests.test_human_review_effectiveness_223`: 6 tests OK.
* `ruff check` on `ai_tasks.py` clean. `mypy` in `src/core` reports 3 errors (missing OpenTelemetry stubs, one unused ignore); the count is identical without this change.
* Not deployed: the live demo runs the earlier revision, so the field cannot be seen live in this run.
