## Scope and boundaries

Refs #138. Synthetic demo, desktop only. Only read-only GitHub and Azure commands ran. Nothing was
created, dispatched, pushed or changed, and no sign-in credential was read. No browser proof applies;
none of the six criteria has a user interface. Baseline: [fifth run](./issue-138-live-r5-2026-11-18.md).

## Code change (first unmet criterion)

`infra/scripts/pipeline.py` gains `verify-federation`. The Entra side of criterion 1 had no check:
`verify-environment` only covers GitHub environment protection. The new operation lists an identity's
federated credentials (managed identity in `ama`, or app registration) and fails unless at least one
exists, every credential has the GitHub issuer, audience `api://AzureADTokenExchange` and subject
`repo:<owner>/<repo>:environment:<environment>`, and an app has no client secret. Output is withheld.
Test `test_federation_check_requires_exact_environment_subject`: 34 pipeline tests pass; a mutation
that ignores the subject made it fail. Mutation output observed; raw output not retained.
