## What the code already enforces

`AnalysisPolicy.validate` in `src/core/src/zava_forward/core/sensor_analysis.py` raises `RESEARCH_GATE_REQUIRED` when a threshold is labelled `SOURCED:` without a `ResearchGate`. The gate holds three non-empty label references, one each for R1, R2 and R3, and rejects empty values with `INVALID_RESEARCH_GATE`. The references enter the policy digest, so changing one changes the version provenance. An exercise-labelled policy needs no gate and its digest is unchanged by a null gate.

`test_sourced_threshold_requires_research_gate` in `src/core/tests/test_sensor_analysis.py` covers each of these cases.

Command run on 2026-11-23 from `src/core` with `PYTHONPATH=src:tests`:

```text
python3 -m unittest test_sensor_analysis test_sensor_scenarios -q
Ran 34 tests in 5.849s
OK (expected failures=1)
```

The guard proves the pipeline cannot label a threshold as sourced without attested references. It does not prove the research behind the references exists or is sound; the code only checks that a label is present, by design ("attested, never inferred").
