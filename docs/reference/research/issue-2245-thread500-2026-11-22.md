## Change

One regression test, `test_thread_creation_takes_the_write_lock_at_most_twice` in `src/core/tests/test_chatthreads.py`, bounds the write transactions in thread creation, because each one is a chance for the lock wait to end in a 500. No source change; a 503 mapping for lock timeouts was rejected as an unevidenced handler change.
