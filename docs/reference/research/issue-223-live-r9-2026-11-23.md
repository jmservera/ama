Refs #223. Scope is the synthetic desktop demo under the owner decisions of 2026-11-18. [Run 8](issue-223-live-r8-2026-11-23.md) began retaining `review_seconds` in each review record but nothing summed it. This run adds that total to `ai_tasks.live_report`. Tier FULL (source change); only targeted checks were run, not the complete gate.

## Change

* `src/core/src/zava_forward/core/ai_tasks.py`: `live_report` returns `review_effort`, keyed by task, with `timed_reviews`, `total_seconds` and `mean_seconds`. Records without a numeric `review_seconds` are left out, and tasks with no timed review do not appear. The existing `tasks` rows are unchanged.
* `src/api/tests/test_ai_tasks.py`: `test_live_report_totals_measured_review_effort` reviews two of three summaries (60 s and 180 s) and expects 2 timed reviews, 240.0 s total and a 120.0 s mean; the unreviewed record does not count. It runs against the JSON and SQL stores.

## Evidence

* `test_ai_tasks.py` in `src/api`: 87 tests OK (the "law store is not loaded" line in the output is a logged expected error in existing tests).
* `src/core` `test_human_review_effectiveness_223` and `test_management_tokenomics_invariant_100`: 12 tests OK.
* `ruff check` clean; `mypy` in `src/core` reports 3 errors that predate this change.
* Not deployed: the owner decisions allow no production change, so the live app still serves the run 7 behaviour. The live retention of reviewer, reason and source was shown in [run 7](issue-223-live-r7-2026-11-23.md).
