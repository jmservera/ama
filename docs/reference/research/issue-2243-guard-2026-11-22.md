## Change

* `infra/sql/resident-assistant.sql`: `resident_ai.reserve` returns a second column `refusal` (`ledger_expired`, `budget_spent`, `resident_rate_limit`, `duplicate`, `budget_missing`); column 0 is unchanged.
* `aoai.py`: `SqlAccounting.reserve` raises `AssistantUnavailable` with the first three reasons; the resident label and the console reason now read "the AI ledger has expired and needs a new end date", "the AI budget is fully reserved and needs an owner top-up" or "you have reached the hourly AI question limit". A procedure that returns one column, or an unknown reason, keeps `usage_limit`.
* Tests: `test_resident_aoai.py` (reasons, old-procedure compatibility, label) and the opt-in loopback SQL tests updated.

Deployment order: the owner applies the new procedure, then extends `resident_ai.budget.expires_at`; the new image can roll before or after.
